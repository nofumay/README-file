# Meu Site

Este é um site moderno e responsivo criado com HTML, CSS e JavaScript.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.0

## Estrutura do Projeto

```
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── img/
    └── hero-bg.jpg (necessário adicionar)
```

## Funcionalidades

- Design responsivo
- Navegação suave
- Formulário de contato com validação
- Animações em cards
- Menu de navegação responsivo

## Como Usar

1. Clone este repositório
2. Adicione uma imagem de fundo em `img/hero-bg.jpg`
3. Abra o arquivo `index.html` em seu navegador

## Personalização

- Para alterar cores e estilos, edite o arquivo `css/style.css`
- Para modificar funcionalidades, edite o arquivo `js/main.js`
- Para alterar o conteúdo, edite o arquivo `index.html`
